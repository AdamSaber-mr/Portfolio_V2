# Project: Portfolio V2

Persoonlijke portfolio van Adam Saber. Vite + React + TypeScript SPA.

- `npm run dev` — dev server
- `npm run build` — type-check (tsc) + productie-build
- `npm run preview` — preview van de build

## Git-regels (VERPLICHT)

Vanaf nu **nooit** jezelf, Claude of een andere AI toevoegen als co-author,
contributor of auteur in Git commits.

- Alle Git-commando's (commit, push, branch, merge, etc.) draaien **alleen**
  onder het GitHub-account van Adam Saber.
- **Geen** `Co-authored-by:` regels, **geen** extra auteurs, **geen** verwijzing
  naar Claude/AI als contributor — nergens in de commit message of trailer.
- Commit messages zijn gewone tekst, bijvoorbeeld: `feat: add new dashboard layout`.
- Commit in **kleine, losse logische blokjes** — niet alles in één keer.
- Als een tool/template automatisch een `Co-authored-by` regel zou toevoegen:
  verwijder die expliciet en waarschuw met:
  "Let op: ik heb alle co-author regels verwijderd zodat alleen jouw account als
  auteur in de commit komt te staan."
